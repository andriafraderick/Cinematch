# 🎬 CineMatch — AI-Powered Movie Recommendation Engine

A full-stack Django web application with a hybrid ML recommendation engine that combines collaborative filtering and content-based analysis to deliver personalized movie recommendations.

---

## 🌟 Features

- **Hybrid ML Recommendation Engine** — TF-IDF content-based + SVD collaborative filtering
- **Personalized Recommendations** — Adapts based on your ratings and watch history
- **Cinematic Dark UI** — Obsidian black with amber accents, film-grain texture
- **Full REST API** — JWT-authenticated DRF API for all features
- **Movie Catalog** — 4800+ movies from TMDB dataset with posters, cast, crew
- **User Profiles** — Genre preferences, watchlist, ratings, watch history
- **Live Search** — Real-time movie search in the navbar
- **Browse & Filter** — Filter by genre, year, rating, language

---

## 🧠 How the ML Engine Works

The recommendation system uses three algorithms depending on how many ratings a user has:

| User Ratings | Algorithm | Description |
|-------------|-----------|-------------|
| 0 ratings | Popularity | Bayesian-weighted trending films |
| 1–4 ratings | Content-Based | TF-IDF cosine similarity on genres, cast, keywords |
| 5–19 ratings | Hybrid (light CF) | 70% content + 30% collaborative |
| 20–49 ratings | Hybrid | 40% content + 60% collaborative |
| 50+ ratings | Hybrid (heavy CF) | 20% content + 80% collaborative |

### Content-Based Engine
- Builds a feature "soup" from genres (3× weight), directors (3×), cast (2×), keywords (1×)
- Uses TF-IDF vectorization (5000 features, bigrams)
- Computes cosine similarity between all movie pairs
- Pre-computes top-20 similar movies per film for fast lookup

### Collaborative Filtering Engine
- Builds a User × Movie sparse rating matrix
- Applies Truncated SVD (50 latent factors) for matrix factorization
- Normalizes ratings by subtracting user mean (corrects for generous/harsh raters)
- Predicts ratings for unseen movies via dot product in latent space

### Cold Start Strategy
- Stage 1 (0 ratings): Bayesian popularity ranking
- Stage 2 (genre prefs set): Genre-filtered popularity
- Stage 3 (1–4 ratings): Content-based only
- Stage 4 (5+ ratings): Full hybrid engine

## 📦 Dataset

This project uses the **TMDB Movie Dataset** from Kaggle.

### Required Files

| File | Source | Description |
|------|--------|-------------|
| `tmdb_5000_movies.csv` | [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) | Movie metadata: title, overview, genres, keywords, ratings |
| `tmdb_5000_credits.csv` | [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) | Cast and crew data for each movie |
| `movies_metadata.csv` | [The Movies Dataset](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset) | Additional metadata including poster_path and backdrop_path |

### How to Download

1. Create a free account at **kaggle.com**
2. Download **TMDB 5000 Movie Dataset**:
   - `tmdb_5000_movies.csv`
   - `tmdb_5000_credits.csv`
3. Download **The Movies Dataset** (only need one file):
   - `movies_metadata.csv`
4. Place all three CSV files in the project root (same folder as `manage.py`)

### What Gets Imported
- ~4800 movies with full metadata
- Genres, keywords, taglines, overviews
- Top 10 cast members per movie
- Directors, writers, and key crew
- Movie poster and backdrop image paths (via TMDB CDN)

## 🚀 Local Setup

### Prerequisites
- Python 3.11+
- Git

### 1. Clone the repository
```bash
git clone https://github.com/andriafraderick/Cinematch.git
cd Cinematch
```

### 2. Create virtual environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt --only-binary=:all:
```

### 4. Create .env file
Copy `.env.example` to `.env` and fill in your values:
```
SECRET_KEY=your-random-secret-key-here
DEBUG=True
DATABASE_URL=
SITE_NAME=CineMatch
SITE_TAGLINE=Your AI-Powered Cinema Companion
TMDB_IMAGE_BASE=https://image.tmdb.org/t/p/w500
```

Leave `DATABASE_URL` empty to use SQLite locally.

### 5. Run migrations
```bash
python manage.py migrate
```

### 6. Create admin user
```bash
python manage.py createsuperuser
```

### 7. Download and place datasets
Download the three CSV files from Kaggle (links above) and place them in the project root:
```
Cinematch/
├── manage.py
├── tmdb_5000_movies.csv
├── tmdb_5000_credits.csv
└── movies_metadata.csv
```

### 8. Import movies
```bash
# Import movies and credits
python manage.py import_kaggle --movies tmdb_5000_movies.csv --credits tmdb_5000_credits.csv

# Backfill poster images from movies_metadata.csv
python manage.py shell -c "
import csv
from movies.models import Movie
updated = 0
with open('movies_metadata.csv', encoding='utf-8', errors='replace') as f:
    reader = csv.DictReader(f)
    for row in reader:
        try:
            tmdb_id = int(float(row.get('id') or 0))
            poster = (row.get('poster_path') or '').strip()
            backdrop = (row.get('backdrop_path') or '').strip()
            if tmdb_id and poster:
                count = Movie.objects.filter(tmdb_id=tmdb_id).update(
                    poster_path=poster, backdrop_path=backdrop)
                updated += count
        except: continue
print(f'Updated {updated} movies with poster paths')
"
```

### 9. Build ML index
```bash
python manage.py compute_similarities
python manage.py warm_engine
```

### 10. Collect static files
```bash
python manage.py collectstatic --noinput
```

### 11. Start the server
```bash
python manage.py runserver
```

Visit **http://127.0.0.1:8000**

## 🌐 Deployment (Railway)

### 1. Push to GitHub
```bash
git add .
git commit -m "Initial commit"
git push -u origin main
```

### 2. Deploy on Railway
1. Go to **railway.app** and sign up
2. Click **New Project** → **Deploy from GitHub repo**
3. Select your Cinematch repository
4. Add a **PostgreSQL** database plugin
5. Railway automatically sets the `DATABASE_URL` environment variable

### 3. Set environment variables in Railway dashboard
```
SECRET_KEY=your-50-char-random-secret-key
DEBUG=False
ALLOWED_HOSTS=yourapp.up.railway.app
SITE_NAME=CineMatch
SITE_TAGLINE=Your AI-Powered Cinema Companion
TMDB_IMAGE_BASE=https://image.tmdb.org/t/p/w500
```

### 4. Run post-deploy commands in Railway shell
```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py collectstatic --noinput
```

### 5. Import data (run once after deploy)
Upload your CSV files and run the import commands via Railway shell.

## 🐛 Common Issues

| Problem | Fix |
|---------|-----|
| CSS not loading | `python manage.py collectstatic --noinput --clear` then Ctrl+Shift+R |
| No movies showing | Run `import_kaggle` command |
| No posters showing | Run the `movies_metadata.csv` poster backfill script |
| Recommendations empty | Rate 5+ movies then POST `/api/v1/recommendations/refresh/` |
| `No module named 'core'` | Change `manage.py` to use `'cinematch.settings'` |
| PostgreSQL refused | `net start postgresql-x64-17` |
| Em dash syntax error | Run PowerShell replace: `(Get-Content file.py -Raw) -replace [char]0x2014,'-' \| Set-Content file.py` |
| `warm_engine` fails | Run `import_kaggle` first, then `compute_similarities`, then `warm_engine` |
